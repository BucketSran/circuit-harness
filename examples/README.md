# Examples

This branch keeps the [Chips examples](chips/README.md): EMX, ngspice, Spectre,
VABench, and Analog Design Bench. Other domain examples remain in private history
and backups; their remote reference branches have been retired. See the
[repository scope](../docs/chips/REPOSITORY_SCOPE.md) for current contents and release boundaries.

The [single-experiment entry](../docs/chips/UNIFIED_EXPERIMENT.md) describes how
VABench and Analog runs share configuration and result records while using their
own simulators and scorers.
