# Circuit Harness 任务卡模板

状态：规格草稿。任务卡是供专家和 Agent 协作填写的文档，当前不是可执行配置格式。
未知项写“待确认”，不猜工艺、端口、阈值或命令。

## 身份与来源

- 任务族 / task_id / 版本：
- 电路目的、实际使用场景：
- 来源与贡献者 / 专家确认人及日期：
- 来源资料能否随仓库共享；受限资料如何由授权成员取得：
- 当前状态与已验证范围：

## 模型/程序获得的输入

- 输入文件/参数及格式；单位、层映射、端口和其他约定：
- 固定条件（工艺、环境、测试条件等）：
- 允许修改的变量、范围和禁止改变的条件：
- 预期提交内容：
- 模型可见信息；最终评测保留信息：

## 执行条件与手动基线

- 本机与远端所需软件、版本、环境初始化步骤：
- 工具输入/输出位置约定；实际命令或操作演示引用：
- 可运行的专家参考输入及结果来源、摘要：
- 直接调用工具的复现步骤（实现后填写）：
- 仿真次数、单次/总时间及其他资源限制：

## 判定规则

- 执行完成的条件：
- 结果有效性：缺文件、无效数字、配置不符等如何识别：
- 指标名称、计算来源/公式、单位、方向、阈值与容差：
- 全部必须满足的硬约束：
- 设计不达标与不可评如何区分：
- 需要人工判断的部分、专家认可的证据：

## 夹具与划分

- 成功案例及预期判定：
- 设计失败案例及预期判定：
- 执行故障或结果无效案例及预期判定：
- 开发/校准/封存测试划分；相关设计变体是否应归入同一划分：
- 数据/工具/评分规则变化时的版本更新方式：

## 接入与复现记录

- 对应 converter / Tool / 数据准备 / 评分代码位置：
- 本机运行代码版本与配置摘要；原始 run 及产物引用：
- 第二位成员复现环境、结果、差异与容差解释：
- Agent / 模型 / 工具集合 / memory 设置（使用后填写）：
- 尚未验证与待专家确认事项：
