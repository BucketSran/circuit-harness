# 电路示例

自动 Agent 实验从 [Harbor 模板](harbor/README.md)开始。直接操作者工具可分别使用 [EMX](emx/README.md)、[ngspice RC](../../docs/chips/NGSPICE.md)、[Spectre RC](../../docs/chips/SPECTRE_RC.md)、[VABench](../../docs/chips/VABENCH.md)、[Analog Design Bench](../../docs/chips/ANALOG_DESIGN_BENCH.md) 和[任务构建](task_authoring/README.md)。

这些是通用代码与安全模板，实际任务、版本、路径、许可证和凭据由操作者配置。旧 Apollo Agent 配置已移除，见[迁移说明](../../docs/chips/MIGRATION.md)。
