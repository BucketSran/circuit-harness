# 电路示例

首次实验从 [AnalogBench RLC 快速开始](../analogbench/README.md)开始，随后可以运行 SKY130 OTA 或 [EVAS VA07 候选重放](../evas-va07/README.md)。接入自己的任务按[开发者指南](../../docs/guides/integration.md)准备，再使用 [Harbor 模板](harbor/README.md)。

直接操作者工具包括 [EMX](emx/README.md)、[ngspice RC](../../docs/reference/NGSPICE.md)、[Spectre RC](../../docs/reference/SPECTRE_RC.md)、[VABench](../../docs/reference/VABENCH.md)、[Analog Design Bench](../../docs/reference/ANALOG_DESIGN_BENCH.md) 和[任务构建](task_authoring/README.md)。

示例准备代码与安全模板可以公开，实际任务下载、运行产物、私有路径、许可证和凭据由操作者管理。各示例分别说明来源、版本和验收边界。
