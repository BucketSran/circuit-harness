The minimal Environment lifecycle contract came through the prior AlphaApollo
v2 SkyRL-style environment interface. No verl implementation is vendored in
this clean foundation. The OpenAI-compatible transport consolidates API client
behavior previously implemented in AlphaApollo v3. Source refs and migration
provenance were recorded under docs/design/refactor/ in the upstream history.
Current distribution provenance is summarized in third_party/README.md.

The coding-agent tool output truncation and streaming accumulation behavior in
alphaapollo/common/execution/tools/truncate.py and
alphaapollo/common/execution/tools/output_accumulator.py is adapted from
earendil-works/pi:

Copyright (c) 2025 Mario Zechner

The original implementation is licensed under the MIT License. AlphaApollo's
Python adaptation preserves Pi's tail-truncation and streaming accumulation
semantics while integrating with AlphaApollo's typed tool records,
ArtifactStore, cancellation model, and Podman sandbox execution.
