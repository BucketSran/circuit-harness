# 电路工具规格模板

为实际需要的工具明确接口和验收条件。本模板不会自动注册工具；现有公开入口
由任务会话的 schema 声明，具体调用方式见[接入指南](../guides/integration.md)。

## 任务与能力

- 工具名称、版本与所属组件：
- 解决的电路问题与使用它的任务：
- 候选格式、单位、模型语法和支持的分析：
- 现有入口不能满足需求的具体场景：
- 公开诊断与独立评分的职责：

## 输入与输出

- Agent 可填写的字段、类型、范围、默认值与非法输入：
- 操作者固定的软件、PDK、服务器、许可证和资源配置：
- 返回模型的指标与摘要，以及完整产物的私有证据引用：
- 输入、配置、软件、模型与解析器的版本身份：
- 摘要省略的内容及读取完整公开观测的方式：

## 执行与故障

- 非法输入、依赖缺失、执行失败、设计不达标和不可评的表达：
- 动作预算、期限、输出限额及重试边界：
- 动作/作业身份与幂等规则，未知状态的查询方式：
- 取消、清理、候选冻结与最终评分关联：
- 哪些文件和信息可被 Agent 读取：

## 验收与代码归属

- 参考候选、合法不达标候选与依赖/执行故障的预期结果：
- 本地夹具覆盖、真实后端验收和未覆盖条件：
- 比较新旧版本时固定的任务、模型、工具与预算：

执行接口放在 `circuit_harness/execution/`，Harbor 环境接线放在
`circuit_harness/harbor/`，具体 benchmark 准备放在 `circuit_harness/benchmarks/`。
公开工具通过已有会话或 `circuit_harness/public_mcp.py` 接入，复用原生 Agent
工具循环。测试归入 `tests/chips/` 或对应模块测试，见[贡献指南](CONTRIBUTING.md)。
